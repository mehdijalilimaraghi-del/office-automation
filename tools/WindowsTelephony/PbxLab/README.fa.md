# آزمایش تماس داخلی روی ویندوز

نصب و نمایش نسخه قبلاً تأیید شده است؛ نصب مجدد یا بررسی دوباره نسخه لازم نیست.

۱. فایل ZIP را روی کامپیوتر مرکز تلفن در یک پوشه معمولی باز کنید. Start-PbxLab.cmd را اجرا کنید؛ آدرس شبکه خودکار از ویندوز خوانده می‌شود و داخلی‌های اولیه 1001 و 1002 هستند. برای داخلی‌های بیشتر در آماده‌سازی اولیه، پارامتر Extensions اسکریپت Configure-PbxLab.ps1 قابل استفاده است.
۲. صفحه راهنما خودکار باز می‌شود و آدرس سرور، دامنه، داخلی‌ها و رمز اختصاصی هرکدام را نشان می‌دهد. این صفحه خصوصی است و نباید برای بررسی ارسال شود.
۳. روی دو کامپیوتر شبکه نرم‌افزار تلفن SIP مانند MicroSIP نصب یا نسخه قابل‌حمل آن را اجرا کنید: https://www.microsip.org/downloads — راهنمای رسمی: https://www.microsip.org/help
۴. در Add Account برای هر کامپیوتر یک حساب متفاوت بسازید: SIP Server همان «آدرس سرور» صفحه، Domain همان «دامنه»، Username و Login همان داخلی، Password رمز همان ردیف، Transport برابر UDP. در تنظیمات صدا PCMU/PCMA را فعال کنید. آدرس صفحه را جایگزین مثال‌های اینترنتی کنید.
۵. پس از آنلاین شدن حساب‌ها، از 1001 شماره 1002 را بگیرید؛ زنگ خوردن، پاسخ، شنیدن صدا در هر دو جهت و قطع تماس را بررسی کنید. 9196 برای شنیدن بازگشت صدای خودتان است.
۶. برای پایان، `Stop-PbxLab.cmd` را اجرا کنید. برای ارسال نتیجه یا مشکل، `Collect-PbxLabDiagnostics.cmd` را بزنید و فقط JSON تولیدشده را ارسال کنید.

در صورت نمایش درخواست دسترسی شبکه ویندوز، فقط شبکه خصوصی و مورد اعتماد سازمان را انتخاب کنید. اگر اتصال از کامپیوتر دیگر انجام نشد، گزارش را ارسال کنید؛ این ابزار فایروال را تغییر نمی‌دهد. پورت پیش‌فرض SIP برابر 5160 و پورت‌های صدای UDP از 17000 تا 17199 هستند. استفاده از اینترنت عمومی، انتقال پورت روتر و NAT در این آزمایش در نظر گرفته نشده است.

اجرای مجدد حساب‌ها را حفظ می‌کند. برای پروفایل آزمایشی جداگانه از پارامتر `-LabRoot` در اسکریپت استفاده می‌شود؛ فایل‌های حساب را دستی ویرایش نکنید. این مرحله تنظیمات نصب اصلی یا سرویس ویندوز را تغییر نمی‌دهد و به مودم وصل نمی‌شود. مدیریت داخلی‌های کاربران و واحدها در اتوماسیون، اتصال خط تلفن، انتقال تماس و انتقال تنظیمات به کامپیوتر دیگر هنوز آماده نیستند.

اطلاعات حساب‌ها فقط در پوشه خصوصی کاربر `%LOCALAPPDATA%\OfficeAutomation\Telephony\PbxLab` نگهداری می‌شود. فایل‌های آن را در پوشه اشتراکی کپی نکنید. فایل گزارش هیچ رمز یا پیکربندی خامی ندارد.
اگر IP کامپیوتر عوض شد، ابتدا Stop-PbxLab.cmd و سپس Start-PbxLab.cmd را اجرا کنید. برنامه آدرس قبلیِ حذف‌شده را خودکار اصلاح می‌کند؛ رمز داخلی‌ها تغییر نمی‌کند. SIP Server و Domain هر دو تلفن را مطابق صفحه حساب‌ها به‌روز کنید. اگر چند شبکه معتبر وجود داشته باشد و انتخاب قطعی ممکن نباشد، برنامه بدون تغییر تنظیمات متوقف می‌شود.
