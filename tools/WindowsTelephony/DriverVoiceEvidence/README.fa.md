# گزارش مسیر صوتی درایور مودم

Collect-ModemDriverVoiceEvidence.cmd را روی کامپیوتر مودم اجرا کنید. نیازی به برقراری تماس، بازکردن درگاه یا دسترسی Administrator برای نوشتن تنظیمات نیست؛ ابزار فقط تنظیمات موجود درایور نصب‌شده را می‌خواند و در صورت نداشتن دسترسی آن را گزارش می‌کند. فایل modem-driver-voice-evidence.json در کنار برنامه ذخیره می‌شود.

گزارش شامل مشخصات فنی مجاز، VoiceProfile، تنظیمات سرعت و تبدیل صوت WaveDriver و فرمان‌های پخش/ضبطِ تعریف‌شده توسط درایور است. رمز، شماره تماس، داده فکس و صدا جمع‌آوری نمی‌شوند. هیچ مقدار رجیستری یا تنظیم مودم تغییر نمی‌کند. نبودن اطلاعات به‌صراحت گزارش می‌شود و با مقدار پیش‌فرض ساختگی جایگزین نمی‌شود.

این اطلاعات مسیر پیشنهادی خود درایور را مشخص می‌کند؛ به‌تنهایی ثابت نمی‌کند VentaFax در تماس قبلی حتماً از همین مسیر استفاده کرده است. تفسیر داده‌های باینری و شناسه‌های تبدیل باید با مستندات همان درایور انجام شود.

آزمون فیلتر و نگاشت: Test-ModemDriverVoiceEvidence.ps1 با Windows PowerShell 5.1؛ این آزمون به مودم یا رجیستری دست نمی‌زند.
